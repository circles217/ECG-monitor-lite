# 便携式心电监测软件（ECG Monitor）

基于 Android 的便携式心电监测软件，配合自研蓝牙心电采集硬件，实现心电波形的实时显示、多参数自动分析与数据导出。

## 一、项目简介

本软件运行在 Android 手机上，通过蓝牙低功耗（BLE）连接配套的心电采集设备，实时显示心电波形，并自动测量心率、RR 间期、QTc 间期、QRS 时限、PR 间期、ST 段偏移六项参数。软件采用自相关分析、斜率法等算法在手机上完成信号处理，无需专业操作经验，打开即用，适合日常健康监测、运动前后自测和数据记录等场景。

## 二、硬件说明

软件配套的采集硬件为实验室自研的简易心电采集模块，主要技术规格如下：

- **通信方式**：蓝牙低功耗（BLE），手机完成扫描、连接、服务发现与特征值订阅。
- **数据协议**：数据帧以 `0x20` 为命令头，载荷为 8 位无符号数采样值。
- **电压换算**：采样值按 `mV = 原始值 × (3.3 / 255)` 还原为毫伏电压。
- **采样率**：标称 512Hz，实测约 527Hz，偏差约 3%。软件会根据数据到达速率自动校准实际采样率，保证时间类参数的准确性。
- **导联方式**：单导联，采用常规心电导电电极。
- **供电**：由设备自带电池供电，无线缆束缚，便于随身测量。

> 提示：硬件由指导老师临时研制，属于教学/实验用途；软件对采样率和信号质量做了自动校准与验证，以实测数据为准。

## 三、功能特性

- **蓝牙连接、实时波形**：BLE 配对后，心电波形以约 60 帧/秒流畅滚动显示，支持平滑自动缩放。
- **六项参数自动测量**：心率、RR 间期、QTc、QRS 时限、PR 间期、ST 段偏移自动提取并实时显示，超出正常范围自动提示。
- **冻结并滤波分析**：波形可暂停，对该段数据进行离线零相位滤波，并与原始波形叠加对比。
- **深入分析**：对整段记录自动统计各参数平均值，并定位异常出现的时段。
- **记录并导出**：按秒记录参数并导出 CSV 文件（UTF-8 带 BOM），Excel 可直接打开。
- **模拟模式**：无硬件时内置模拟心电数据，可体验全部功能。

## 五、使用说明

1. 开启手机蓝牙，进入软件，点击"扫描并连接"，选择对应设备完成配对。
2. 贴好电极、保持安静，等待波形稳定后即可查看实时参数。
3. 需要细看某段波形时，点击"冻结并滤波分析"。
4. 想看整段统计时，点击"深入分析"。
5. 需要保存数据时，点击"开始记录"，测量结束点击"停止并导出"，CSV 文件保存在应用外部存储目录 `Android/data/com.ecg.monitor/files/Download/ECG/`，可通过文件管理器或分享功能取出。

## 七、主要功能详解

- **采样率自动校准**：统计单位时间到达的数据量推算实际采样率，校准后 RR、QTc 等时间参数不再受采样率偏差影响。
- **信号滤波**：实时路径采用"去基线 + 平滑"的因果滤波，保证低延迟；离线路径采用中值滤波估计基线 + 前后向零相位平滑，在去除基线漂移的同时不引入相位偏移。
- **心电参数分析**：以自相关分析确定心跳周期，用第 90 百分位阈值和"峰高—谷底"锐度评分定位 R 波，再以斜率法测量 QRS 时限，并计算 PR、QTc、ST 等形态参数；对超出生理范围的结果（如心率大于 200 次/分）判定为噪声干扰并剔除，对连续量采用历史中位数平滑防止显示跳变。

## 八、数据导出格式

CSV 文件列：`时间(秒),心率(bpm),RR间期(ms),QTc(ms),QRS(ms),PR(ms),ST(mV),状态`。文件带 UTF-8 BOM，可在 Excel 等常见表格软件中直接打开。
